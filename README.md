# Pesquisa Culturama

Projeto desenvolvido com foco na criação de uma interface web para pesquisa cultural, permitindo a coleta e organização de dados de forma simples e intuitiva.

## 🚀 Tecnologias utilizadas

* HTML5
* CSS3

## 💻 Sobre o projeto

Este projeto foi desenvolvido durante meus estudos na plataforma Alura, com o objetivo de praticar conceitos fundamentais de desenvolvimento front-end, como estruturação de páginas, estilização e organização de layout.

## 🔗 Acesse o projeto online

https://danieeltrindade.github.io/pesquisa-culturama/

## 📚 Aprendizados

* Estruturação semântica com HTML
* Estilização com CSS
* Organização de componentes visuais
* Publicação de site com GitHub Pages
